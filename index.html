how to use
01
Fork or clone
Head to the repo and fork it to your GitHub account, or clone it directly.
git clone git@github.com:kayspace/portfolio-template.git
02
Pick a template
Each template lives in templates folder. Open the one you want and edit template{number}.html — all placeholders are clearly marked.
03
Ship it
Deploy to Vercel, Netlify, or GitHub Pages in one step. No build process, no config files, just drop the folder.
